# Improvement Backlog

Alfred's queue of proposed changes to the team. Items are added during task execution and `/review-team` runs. Items are implemented during `/evolve`. Nothing is changed without Alfred reviewing and the user confirming significant changes.

---

## Priority Levels

| Priority | Meaning |
|----------|---------|
| 🔴 **Critical** | Agent is actively causing quality failures — fix immediately |
| 🟠 **High** | Recurring pattern causing rework — fix this week |
| 🟡 **Medium** | Improvement that would meaningfully raise quality |
| 🟢 **Low** | Nice-to-have enhancement |

---

## Change Types

| Type | What it is | User confirmation needed? |
|------|-----------|--------------------------|
| **Prompt fix** | Minor update to an agent's instructions | No — Alfred does it |
| **Role expansion** | Agent gains a new responsibility | Yes — Alfred proposes |
| **New agent** | Adding a specialist to the team | Yes — Alfred proposes + drafts |
| **Agent retirement** | Removing an underperformer | Yes — Alfred explains why |
| **Agent replacement** | Retiring one, creating a better version | Yes — Alfred shows before/after |
| **Skill/plugin add** | New tool for the team | Yes — goes through tech-curator vetting |
| **Rule change** | Update to Alfred's standards or protocols | Yes — Alfred explains impact |
